# OOP Practice

A focused collection of C++ practice programs covering object-oriented programming fundamentals.

## Topics

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors and methods

## Purpose

This repository contains small exercises used to understand and practice OOP concepts before applying them in larger software projects.

## Running an Example

Compile a C++ source file with a C++17-compatible compiler:

```bash
g++ -std=c++17 filename.cpp -o program
./program
```

## Improving the Repository

Future exercises will use descriptive filenames, consistent formatting, comments where they add value, and separate examples from larger projects.
